# 105 — 调研文献书目与可比性判定

分支：`claude/peaceful-kare-5bb350`。本文件是 2026-10-22 文献调研（见 [104号](104-导师汇报报告与文献对标.md) §4 与 `results/p2-2-allrows-lit-20261022/related_work.json`）的**书目登记 + 可比性判定**：每篇论文能不能和我们的方法对比、按什么标准判、判不了的原因是什么。机器可读的完整字段（指标定义、留出方式、可引数值、未核实项）都在 `related_work.json`，本文件不重复数值、只给结论与依据。

## 1. 判定标准

一篇论文可与我们的方法**直接对比 Q95**，须同时满足：

1. **口径恒等**：q-error = `max(ĉ/c, c/ĉ)`（倍数空间、两侧下界 1）——这条几乎所有学习式论文都满足；
2. **整库留出零样本**：目标库不训练、不微调、不选 checkpoint——这是我们协议的核心，也是绝大多数论文不满足的一条；
3. **统计单元一致**：PRICE 的 Q-ERROR 算在**分解后的子查询**上（LLM-CE 脚注 3 证实），我们的缓存行与之一致；整条查询单元的论文（FLAT/DeepDB/Naru/LLM-CE）数字不与我们同单元；
4. **不依赖目标库数据侧信息**：用目标库直方图/真值单表基数训练的，违反本项目红线。

判语分四档：**直接可比** ／ **经 PRICE Table 2 复跑后同列**（PRICE 在统一 harness 里重跑过它们）／ **不可直接比（设定不同）** ／ **不可比（无基数指标或依赖目标库数据）**。

## 4. 结论

- **能直接与我们对比的只有一篇：PRICE。** 这正是报告第 08 节把全部对比火力放在它那张表上的原因；已撤回的 2502.14350 是同赛道的第二条线，只能提不能引。
- **CardOOD / GRASP 的数「口径同、设定不同」**：可以放在同一单位下读，不能写成胜负。它们对我们的真正价值是**可移植的训练杠杆**（鲁棒目标、偏序自监督）和**缺失证据类型的模板**（E2E/P-ERROR 的测法）。
- **AHCE/DACE 与 BIRD 登记为不可比/排除项**，CardBench 挂「核实后再判」——这是防止后续写作误引的负面清单。
- 作者名单、题名、卷期、日期已于 2026-10-23 用 arXiv API 与 Crossref 逐条核对；MSCN/FLAT/Naru 的 venue 按其论文自述标注，未再逐条反查出版方 DOI（风险低）。
