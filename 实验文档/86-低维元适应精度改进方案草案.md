# 86 低维元适应精度改进方案草案

日期：2026-10-18（Asia/Shanghai）。状态：`draft / implementation_not_started / execution_not_authorized`。
本轮授权仅为写方案与模型审查，不包含修改模型、真实训练、服务器访问或目标评估。
代码基准为 `3dc0b9e452c2d3db5bc43533f8d24cb94d021d7d`；对应审查见
[模型审查报告](../reports/model-accuracy-review-20261018.md)。本文不是现有 81 号协议的修订，也不改变旧实验的停止决定。

## 1. 要回答的问题

在相同源训练库、样本计划、训练预算和 PG 锚定下，把部署时更新的自由度从整个 head
改为四维任务系数，并在元训练中学习其修正方向，能否降低未参与训练数据库的
4+ 表 standard unique-query Q95，同时不明显损害低基数复杂查询？

这是针对少样本更新泛化的假设，不是认定“65 参数太多”或“已经证明表征不足”。
现有 Meta65 已经包含 head/last 的元训练；本方案的新变量是参数化的适应子空间，而不是首次引入元学习。

依据与反证：

- 80 号：`R_head3=37.8033`、`T_all3=42.4364`，扩大内循环范围未通过筛选。
- 低维 Gate 1：none / SmoothL1-last3 / MSE-last3 / ridge 的 4+ Q95 分别为
  `41.4408 / 41.0358 / 39.3235 / 99.2306`；ridge 的 15/15 support MSE 改善没有转化为 query 收益。
- MSE-last3 的 low4 Q95 从 `142.3801` 上升到 `171.0273`，不能只看整体改善 5.11%。
- 这些结果只否定已测试配方；不证明所有低维适应无效，也不支持继续扩 ridge 的 lambda 网格。
- S4/S5/S6、attn/attn_pair、sum_map 的旧结论不变；本轮不同时重启这些路线。

低维结果来源：分支 `feat/meta65-gate1-verifier-20261018`、提交 `9360228` 的
`实验文档/84-Meta65低维闭式适应Gate1执行结果.md` 和
`reports/meta65-gate1-verifier-rebuild-20261018.json`。它们不是本分支重跑所得。

## 2. 模型定义：四维任务系数，不是四个总参数

保留 sum64 的输入变换、编码器、池化、PG 锚定和原 head。记原 head 最后一层前的
64 维向量为 `h_theta(q)`，原输出为 `f_theta(q)`，并定义：

```text
z_theta(q) = concat(h_theta(q), 1)               # 65 dimensions
A in R^(65 x 4)                                # meta-learned basis parameters
P(A) = reduced_QR(A).Q                         # P.T @ P = I_4
prediction(q, u) = f_theta(q) + z_theta(q).T @ P(A) @ u
u_0 = zeros(4)                                # reset independently in every episode
```

部署内循环只更新 `u`，theta 与 A 不变。外循环用 disjoint query 的 SmoothL1 更新
theta 和 A；不把 query 标签送入内循环。总增量参数为 A 的 260 个元素，部署适应变量为
4 个；基础 sum64 是 132,545 参数，不是旧 set 的 99,777。

选择正交列是为了避免 A 任意放大时，同一 inner_lr 对应的函数更新幅度也任意放大。
它不限制 h 的范数，不保证输出变化小或精度提高。无额外学习率倍数、gate、ridge、输出裁剪或按库参数。

初始化与梯度必须明确：

1. A 用独立固定 RNG seed 1729 产生的非零高斯矩阵初始化；theta 共用 seed42 的相同基础权重。
2. A必须满列秩且非零；直接线性基P与u双零时，合成检查已复现死分支，A=0也不满足QR的有效前提。
3. 每步 `u_next = u - 0.001 * stop_gradient(grad_u L_support)`，共 3 步；采用一阶近似。
4. query 前把最终 u 视为常量，仍对 query 侧的 h、f、P 求导；不能 detach 整个预测分支。
5. u 不是共享 optimizer 参数，不写回跨 episode 状态，不从上一 episode 或已适应 checkpoint 续接。
6. QR 的符号约定、秩退化检查和 CPU/GPU容差必须在实现验收时冻结；QR 失败或非有限即停止，不能换分解器求通过。

`u=0` 时必须精确还原本臂的原预测；这不意味着训练完成后它与另一臂的 none 相同。
一阶近似只定义梯度算法，不保证是完整展开目标的精确导数；不能拿完整展开 finite difference
直接认证一阶梯度。应分别核对固定 fast-u 的解析梯度及明确 detach 的参考实现。

## 3. 最小对照：一个候选，加必要的机制对照

| 臂 | 内循环 | 外循环 | 作用 |
| --- | --- | --- | --- |
| R_head3 | 原 head，3 步 | 原全部 theta | 现有方法基线 |
| F_subspace4 | 四维 u，3 步 | theta；A 固定 | 区分低维约束与显式学习 A 的收益 |
| L_subspace4 | 四维 u，3 步 | theta 与 A | 唯一预先指定候选 |

F/L 的 A 初始值完全相同。三臂 theta 初值、数据库/episode/support/query身份与顺序相同，
新增参数初始化不得消耗原 episode RNG。F 仍可通过 theta 学习与固定子空间配合的表示，
因此不能称为“完全没有学习的适应器”。L/F 比较的是显式更新 A 的训练干预，不是静态矩阵的纯效果。

每臂都评估 `none` 与自己的冻结适应算子。R/L 是实用方法对比，改变了适应参数化与训练轨迹；
不能据此把全部收益归因于“只有四维”。如果 L 与 F 相近，只能说没有显式学习 A 的额外证据。
F 不得在 L 失败后被追认为替代候选。

固定训练建议：4000 outer steps、meta_batch=4、accumulation=1、query_size=64，
K 从 `[5,10,20,50,100]` 均匀抽取，outer Adam lr=3e-4，inner lr=1e-3、3步，
SmoothL1(beta=1)、outer clip norm=1、FP32。只取 4000 步 `last.pt`；无 best 选择、early stop、resume。
本轮不同时更换 loss、采样、特征、宽度、K 集或一阶近似。

- `imdb/stats/genome/ergastf1` 继续禁入；不读取其样本或新作误差分析，不初始化为 PRICE 提供权重。
- 23 库历史 checkpoint 包含两个 assessment 库的训练曝光，不得作为本方案初始化。
- 21 库新基线不可直接用历史 23 库的 37.8033 作为正式门槛分母；三臂必须同 split 同 plan。
- 81 号的 50-cell baseline 若另获授权完成，可作背景记录；本文不依赖其有利结果，不因其结果改方法。
- 实施前登记 assessment 是否已在其他任务揭示。如果已揭示，明确降为历史曝光的评估集；
  不换库、不掩盖曝光，也不把新 seed 当成新数据库或独立盲测。

评估 K 固定20、5个 support run。沿用已冻结身份策略，support 从完整100条计划取前20；
query 排除整个100条集合，不能重建只排除20条的计划改变分母。三臂必须相同 query_hash、真值和顺序。
训练与评估 query 均按现有 unique 口径；cache 原始行数不能冒充 unique 数。
跨 run 的重复 query 不是新的独立样本。

## 5. 主指标、保护条件与结论层级

本节为建议门槛，须在任何新真实结果揭示前由用户确认并冻结；不得覆盖旧实验门槛。

```text
Q_i = exp(abs(max(raw_log_pred_i, 0) - log(max(true_i, 1))))
Q95(db, run) = percentile(Q_i for all unique 4+ queries, 95, method="linear")
M_V(arm, op) = mean_over_3_db(mean_over_5_run(Q95(db, run)))
low4 = (n_tables >= 4) and (true < 100)           # evaluation only, never routing
```

单 seed 开发候选必须全部满足：

1. `M_V(L, adapted) <= 0.90 * M_V(R, head3)`。
2. 每个 V 库 all 与 4+ 的 Q50/Q95（先按五 run 算术平均）不高于 R-head3 的1.10倍。
3. 每个 V 库的 low4 Q95 不高于 R-head3 与 L-none 各自的1.10倍；每run至少30条，缺失或不足不能当通过。
4. `M_V(L, adapted) <= 0.98 * M_V(L, none)`，且每个 V 库4+ Q95不高于L-none的1.10倍。
5. 完整分母、身份配对、checkpoint/state隔离、数值和资源认证全部通过。

第4条的2%是事前提出的最小适应收益要求，不是显著性界或效果预测。所有相对变化都使用
对应同次运行分母，不混用 mean ratio 与 ratio of means。all/4+/low4 的 Q50/Q95、Q99、
raw log error、逐 run 配对、support loss 与更新范数全部报告，不能只报告主门槛。

L/F 的主指标比值和逐库差值固定报告，不用于从多候选中择优；只有显式更新A相对F也有
可重复收益时，才支持“学到的子空间有额外作用”。本轮不会仅凭单seed宣称该作用已确认。

开发失败：归档 `no_development_candidate` 后停止，不揭示本方案的 assessment 端点，
不扩 d/lr/lambda/seed/K，也不切换F。开发通过：先封存模型、配置和选择记录的SHA，
再经独立授权一次性评估 H，按两库分别报告；不把5库混成候选macro，不依据H选择或修改模型。
H结果仅支持描述性迁移结论。多seed、真正新数据库和公平PRICE对照均属下一份协议，而非自动续跑。

## 6. 分阶段实施及验收

### A. 实现前的CPU契约验证

未来实现仅触及独立模型变体、适应函数、专用runner/config和对应测试；不修改旧冻结闭包。
可复用现有严格 checkpoint、batch 与指标逻辑，但不得复用固定23库/60-cell的旧启动门。

必须先写能失败的测试：

- 同theta下 u=0 逐元素还原原sum；旧checkpoint输出、梯度和配置加载不变。
- 在事前构造的非退化合成样例上，非零A、零u产生support更新和有限非零query侧A梯度；
  合法真实episode可因残差投影为零或梯度抵消而零梯度，不得因此删任务。零A负例必须被拒。
- P正交、QR符号处理、rank不足/NaN拒绝、固定seed重放一致。
- inner仅变u，outer更新theta/A；F不更新A；episode先后顺序不污染模型或任务状态。
- 改query标签不影响u；训练/部署三步数值一致；独立解析线性样例验证first-order梯度。
- 计数、padding、空过滤组、合法置换、CPU/GPU桥接、保存/重载、哈希变化与完整分母。
- 21/3/2/4集合隔离、旧23库checkpoint拒绝、V失败不能读取H、任意目标路径拒绝。

本轮只做过小张量梯度探针，尚未实现本方法，也未完成上述未来验收。

### B. 有界预检与冻结

实现后先本地专项/完整回归及独立diff审查，再单独申请CPU/GPU微预检。
预检只用T/V，不读取H特征/标签或目标；三个臂各2个outer更新，V固定run0，
各算子至多32条固定query，共 `3 arms x 3 V x 2 operators = 18 microcells`。
预检只认证工程，不报研究收益；2步资源不能外推4000步，正式预算须有完整轨迹证据或单独授权的有界profile。
正式训练前先只读核对冻结V计划每库每run的low4计数满足第5节；不足即blocked，不改query集合、
不补样或改门槛，也不提前读取H来决定是否继续。

### C. 单次源侧正式筛选（另行授权）

- 三臂各4000更新，共12000更新；基础参考每臂16000 episodes，3 inner + 1 outer backward/episode。
- V评估为 `3 arms x 3 databases x 2 operators x 5 runs = 90 cells`。
- 通过开发门后H评估为 `3 arms x 2 databases x 2 operators x 5 runs = 60 cells`，需另行授权。
- 建议总计算硬上限8小时、RSS12GiB、VRAM8GiB、输出1GiB，单张现场空闲GPU；
  这是待profile确认的上限，不是耗时/内存预测。现有81号approval和binding不能复用。
- 记录每臂样本曝光、实际backward/optimizer计数、wall time、参数量、内外更新范数与clip比例。
  F/L参数化成本不同，不能按相同步数宣称完全等计算成本。
- 忙、超限、非有限、缺预测、错配、hash变化即停止，只清理自有进程；不自动retry/resume/换卡/补臂。

## 7. 何时转向其他方向

若CPU契约就失败，先修拟议实现，不消耗真实训练预算。若工程通过但开发失败，保留负结果，
不能将其包装为证实“特征已到上限”。下一条路线须另立方案：

1. support覆盖：固定K，比较随机与仅依据可观测输入的分层/多样性抽样；所有模型共享support，计入选样成本。
2. 条件关系信息：区别旧sum_map、普通attention与新的信息来源；没有同版本源表与真实条件统计时，
   不承诺图模型能够恢复过滤条件下的join-key相关性。

不在本方案中同时尝试这两条路线，不降低旧门槛，不以不断追加配置代替可证伪的实验。
