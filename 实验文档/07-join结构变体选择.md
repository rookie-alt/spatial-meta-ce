# 07 join 结构变体：4000 步源验证选择（2026-09-27）

接 `06-join结构诊断与方案.md`。三变体 + 原模型，每个 3 seed，全部续训到 4000 步（early stop 规则不变）。

## 1. 源验证 macro log-Q95（plan-seed 2718，默认适应 5 步/1e-3/all）

| 变体 | 参数量 | s42 | s43 | s44 | 均值 | 标准差 | 停止步 |
|---|---:|---:|---:|---:|---:|---:|---|
| set（原模型） | 99,777 | 2.6625 | 2.6620 | 2.6418 | 2.6554 | 0.012 | 2300 / 2900 / 2500（早停，best 均在 2000 步前） |
| **A. sum** | 132,545 | 2.5990 | 2.6479 | 2.6064 | **2.6178** | 0.026 | 3000 / 3000 / 3700 |
| B. attn | 199,745 | 2.6399 | 2.7111 | 2.6241 | 2.6584 | 0.046 | 3500 / 4000 / 4000 |
| C. attn_pair | 200,769 | 2.5992 | 2.6921 | 2.6217 | 2.6377 | 0.049 | 4000 / 3600 / 4000 |

- set 在 4000 步预算下**没有改善**（best 与 2000 步完全相同），说明原模型已收敛；多给步数不是 A/B/C 的优势来源。
- **A (sum) 最好**：均值比 set 低 0.038，三个 seed 都比 set 最好的 seed（2.6418）低或持平（2.599 / 2.648 / 2.606，只有 s43 略高 0.006）。Welch t 检验 p=0.12，趋势一致但 3 seed 下不算强显著。
- B 与 set 持平，C 好于 B（0.021），但两者 seed 方差是 A 的两倍，其中 s43 都明显更差。
- **按选择规则（源验证均值最低）选 A**。C 的均值差 A 0.02，但参数多 50%、方差更大，没有理由优先。

- attention 变体在少表（chembl 2 表、telstra 4~5 表）上**变差**，说明它们在简单查询上损失精度。

## 3. 结论

1. 选定 **A. sum** 作为新主模型（源验证依据，未看目标库）。
2. 诊断里"表越多误差越大"的问题，结构改动只缓解了一小部分。PRICE 在 genome 4+ 表上的 Q95 约 60，我们约 1000~3000，这个量级差距大概率**不是**池化方式或 token 交互造成的。更可能的来源是**输入信息**：缓存里没有 join 图（哪一列连哪张表），特征抽取里也没存过滤列所属的表。这需要重建特征，属于更大的改动。
3. 下一步按协议：A 跑一次三目标库评估 + ERM-sum 三 seed 对照。
