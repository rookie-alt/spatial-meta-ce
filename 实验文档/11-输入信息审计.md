# 11 P1：输入信息审计（2026-10-02）

## 1. 目的与范围

P0 固定预算对照未改善源验证 4+ 表尾部误差。P1 检查 join 列→表、过滤列→表、fanout→join 列的关联能否可靠恢复；不把结构信息缺失视为已证实主因。

范围仅为 `configs/data.json` 的 23 个训练库与 chembl/legalacts/telstra 三个源验证库，共 26 个 pretrain workload，预计 1,300,000 行。PRICE-master 和现有缓存只读；本轮不重建缓存、不训练、不读取目标库。重复查询逐行核验，不按 unique query 减少核验行数。

## 2. 代码链路已确认的事实

- `vendor/price_features/features_tool.py:41` 能获得列、表别名、WHERE 等值连接及别名→表名映射；`create_sql_features:338` 使用这些信息生成特征。
- join/filter token 顺序是按表顺序分组，再保留 Column AST 首次出现顺序；同一 join 列只保留一个 histogram，但每条连接有两个有方向的 fanout token。
- 返回值只有四组数值与四个数量；`ref_to_tables` 和 token 所属表/连接端点不随返回值保存。
- `spatial_meta_ce/features.py:84` 将 SQL 从缓存 manifest 中移除，但保留 source_line、query_hash、exact_hash 和 id；`FeatureStore` 与 `batch_samples` 也不提供显式关联索引。
- 提取器按 WHERE EQ 的右侧是否为 Column 判定连接；ON、非等值、OR/IN/BETWEEN、子查询、常量在左侧及同列兼作 join/filter 是需要审计的边界，不推断这些边界一定出现在实际 workload 中。
- filter 选择率已按所属表汇总进入 table token 的 AVI/MINSEL/EBO，故显式关联缺失不等于所有过滤归属信息都丢失。PRICE 同样没有显式 join 图，不能单靠这项缺失解释精度差距。

## 3. 全量核验

独立脚本：`scripts/audit_input_mapping.py`，分支 `audit/p1-input-mapping-20261002`。复用既有 SQLGlot 18.17.0、`read_workload`、FeatureStore 和原 vendor extractor，不改训练与特征生成路径。

1. 每行重算 canonical query_hash，并核对缓存的 id/source_line/exact_hash/query_hash。
2. workload true/PG 对原始特征 FP32 标签和缓存 FP64 cards 分别核对。
3. SQL 推导的 table/join/filter 数量、原特征 counts、缓存 offsets 全量比较。
4. 原 PRICE 四组特征与缓存全量比较；逐条 SQL 在内存中重新调用未修改的 extractor，将 counts/values 与二者比较，rtol=1e-5、atol=1e-7。
5. 核对输入 provenance SHA256，检查审计前后输入大小与 mtime 不变。
6. 按库、表数、谓词类型、语义风险标志分别统计错误；保留失败示例和总分母，不静默剔除失败行。
7. 恢复 SQL 局部 table 索引、join/filter token→table、fanout token→join histogram；不使用跨库 table/column ID。

判定：`alignment_passed` 仅在所有行身份/标签/counts/特征及来源校验通过时为 true；`mapping_recoverable` 只表示数值 token 的结构关联可以恢复，不表示旧提取器正确处理所有谓词语义。语义风险单独报告。

## 6. 审计后的条件决策

- 身份、标签、count 或特征错位：记录问题，停止关联消融，不修补或过滤数据以绕过。
- 对齐通过且结构关联可恢复：优先考虑按 query_hash 的独立映射 sidecar，保持已有四组数值特征不变，而非重建全部缓存。
- 语义风险存在：区别结构关联问题与原 extractor 的过滤逻辑问题，不能在“只加映射”的消融里同时修改数值特征。
- 下一轮实验需另行冻结原 sum、真实关联、打乱关联三个对照；真实与打乱使用相同模型、预算和配对 seeds。query_hash 固定采样，核实 cache→batch→model 真正消费映射；表重排不变性、padding、fanout 方向另需测试。
- 本轮没有自动继续训练或目标评估的任务。
