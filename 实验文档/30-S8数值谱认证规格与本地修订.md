## 1. 事前冻结的工程认证规格 v1

科学参数不变：`RCOND=1e-12`、`NORMAL_TOL=1e-8`、`OBJECTIVE_TOL=1e-8`；Adam、loss、LR、seed、面板及候选门槛不改。设计矩阵与目标按既有方式转 FP64，normalizer 仍 P-only。

1. 每个完整谱必须长 `min(m,n)`、finite、非负、非增；rank 为合法整数且等于该谱在固定 cutoff 下的计数。畸形 metadata 仍抛 `ValueError`，不忽略尾谱。
2. 独立 economy SVD 返回 U/s/Vh，用同一实际矩阵确定尺度。记 `eps=np.finfo(float64).eps`、`d=max(m,n)`、`gamma=d*eps/(1-d*eps)`、`eta=gamma*s[0]`。两个完整谱逐项绝对差必须不大于 `2*eta`，且各自 rank 一致。零矩阵时 eta=0；极小尺度不使用固定 atol 地板，非零尺度的误差界下溢、非法 d*eps 或非 finite 的包络／区间／检查量时停止。
3. **eta 是冻结的工程误差包络，不是对任意 BLAS/LAPACK 的已证明算法误差定理。** gamma 来源是 d 次浮点累积的尺度规则，不把它冒称 SVD 实现的普适后向误差常数。为不信任未检查的 backend，还必须核验独立 SVD 的重构残差和 U/V 正交性：按 smax 缩放的重构 Frobenius 残差 `||A/smax-U diag(s/smax) Vh||F` 及两 Gram 残差的 Frobenius norm 均 <= gamma。任何超界停止，不用扩大系数、换 backend 或调 rcond 救场。记录 NumPy、dtype、矩阵尺寸、eps/gamma/eta 与实际检查量；运行环境另存 NumPy backend 配置。
4. 三个谱（调用者 LS、独立 SVD、参考 LS）使用统一 eta，但 cutoff 的 s[0] 必须是每个谱自身的最大奇异值，不共用独立 SVD 的 cutoff；每个 sigma 的误差区间 `[max(0,sigma-eta),sigma+eta]` 与 cutoff 区间 `[rcond*max(0,s[0]-eta),rcond*(s[0]+eta)]` 比较。每项必须严格高于整个 cutoff 区间，或严格低于整个 cutoff 区间；非零矩阵只要触边／重叠就 `rank_stability=unknown`、`solver_verified=false`。不比较或追认模糊 rank；实际 A 全零且三谱全零时单独定义稳定 rank0。
5. 保留全部旧 metadata、normal residual、objective inequality、同 cutoff 参考预测和 objective 检查。预测/目标原 `rtol=atol=1e-12` 不变；秩亏不比较 theta 逐项。
6. 增加独立保留子空间认证：`p_svd=U[:, :rank] @ (U[:, :rank].T @ target)`，LS 与参考 LS 的预测分别以原 `rtol=atol=1e-12` 对此核验；不因相同 solver 重算即认为独立通过。弃方向不提供原完整线性类最优性保证。
7. `pass/solver_verified` 是上述固定 cutoff **工程数值认证**的合取。`full_linear_optimality*` 永远 False；rank-limited 不等于缺信息。near-cutoff、backend 检查失败或任何比较失败不能用于继续 runner。

这是工程门槛而非机器证明：重构/正交性是有限精度检查，不提供区间算术证明，也不保证跨平台逐比特相同；若 backend 与包络不兼容必须另行审规格，不进行结果导向校准。

## 2. 事前验证清单与边界

- 常量／重复／零列、零矩阵、tiny 非零及尺度变化；跨分解路径的近零扰动应可认证，但不是忽略尾谱。
- cutoff 两侧及精确边界；触边或可扰动跨界必须 unknown，dim 增大不得虚报稳定。
- 包络内／外扰动、伪造尾谱／主谱／rank／预测／objective、非 finite／shape／order 及 backend 重构／正交性负例。
- 验证保留子空间，不拒绝仅在零空间不同的合法系数。
- 本地专项先 RED 再 GREEN，完整 unittest 和改动 Ruff；独立代理审实际 diff 与日志。

### 规格审查澄清（实现前）

独立只读代理有条件批准工程规格；已采用上述严格边界、真实零矩阵检查、按 smax 缩放重构及 Frobenius 正交性检查，不增加分解次数。`gamma` 不是普适 SVD 理论界。维度 d>=4504 时包络可能宽过 rcond；19456 行 full-P 存在丢弃方向时稳定秩不能认证，仍 blocked/unknown。小面板通过不能解除此完整 G1 门槛。本轮不读取服务器旧矩阵、不训练或生成新真实矩阵证明。


### v1.1：合成验收后、再次独立审定的正交性规格修订

v1 实现发现两项健康小矩阵的 U Gram Fro 残差高于 gamma_d；失败日志保留，不追认 v1 通过。
独立代理有条件接受以下修订，且**仅修改正交性门槛**：对 k=min(m,n)，使用 `||U.T@U-I||F/sqrt(k) <= gamma_(d+k)`（V 同理）。这是每列 Gram 误差的均方根工程尺度；d+k 是冻结的工程选择，不是由 dot/norm 算法推导出的普适上界，不能证明各方向误差或真实秩。
重构仍 `||A/smax-U diag(s/smax) Vh||F <= gamma_d`；谱 eta、逐项比较、rank interval、原预测/目标门槛全部不变。分别输出原始/归一正交性残差、阈值和规格 `s8-fp64-spectrum-v1.1`。仍须保留超界负例和旧失败证据；最终 diff/测试独立审查不由规格批准替代。
该段取代第1节第3项及前次澄清中“Gram Fro <= gamma_d”的正交性门槛，其余规格保持。
