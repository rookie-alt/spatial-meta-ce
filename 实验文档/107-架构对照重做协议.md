# 107 — 架构对照重做协议（源侧 · 6 seed · 固定步数）

> 状态：`draft / not_started`。本文冻结实验设计，**尚未训练、未读任何目标库**。
> 分支 `feat/arch-compare-paired-20261024`。

## 1. 为什么重做

2026-09-27 的结构筛选从四种架构里选了 `sum`，但差值小于种子噪声。原始记录
`实验文档/results/arch-20260927/select4k-*.json`：

| 结构 | 三 seed 均值 | seed 样本 SD | 参数量 |
|---|---:|---:|---:|
| set | 2.6554 | 0.0118 | 99,777 |
| **sum（历史选中）** | **2.6178** | 0.0264 | 132,545 |
| attn | 2.6584 | 0.0464 | 199,745 |
| attn_pair | 2.6377 | 0.0485 | 200,769 |

sum 比 attn_pair 低 0.020，**小于 attn_pair 自身的 SD 0.049**。
07 号记 Welch p=0.12，08 号记「差异都在 1 个标准差以内」——历史文档从未声称显著，
但后续叙述里「选了 sum」被当作结论沿用。**本协议的目的不是推翻 sum，而是给出
一个能支撑或否证该选择的对照。**

## 2. 原对照的三处混杂

1. **checkpoint 选择偏差**：每个臂用早停选出的 `best.pt`，早停依据
   `validation_seed=1729` 的 episode 计划，而评估用 `plan_seed=2718`。
   两套计划、同一批库，等于每个臂都在被报告的库上被挑过一次。
2. **指标与主指标不一致**：选择用全表 macro **log**-Q95（`scripts/arch_select.py`），
   项目主指标是 **4+ 表桶 macro Q95**（Q 空间）。用平均指标选结构，不保证对尾部最优。
3. **容量未匹配**：attn/attn_pair 参数量是 sum 的 1.5 倍。本协议**不解决**该项，只披露。

## 3. 冻结设计

| 项 | 取值 |
|---|---|
| 架构 | `set` / `sum` / `attn` / `attn_pair`（`configs/meta_*_4k.json`，只差 `model` 与 `steps`） |
| seed | 42, 43, 44, 45, 46, 47（共 6 个） |
| 步数 | 4000，固定；`patience` 提升到 4000 使任一臂都不提前停止 |
| checkpoint | **`last.pt`**，不取 `best.pt` |
| 数据库 | 仅 `chembl / legalacts / telstra` |
| 评估计划 | `--plan-seed 2718`（与历史评估计划一致，便于对照） |
| 主指标 | 4+ 表桶 macro Q95（库内合并 ≥4 表查询算 Q95，再跨库等权算术平均） |
| 次指标 | 全表 macro log-Q95（保留与历史的可比性） |

`set` 臂沿用历史的两键 `model` 形状 `{"width": 64, "use_pg": true}`，
不因新实验改变旧 checkpoint 的可加载性。

### 3.1 seed 42/43/44 的复用规则

这三个 seed 已有 4000 步 run，若服务器上存在对应 `last.pt` 且 metadata 的
`optimizer_steps == 4000`，则**复用**（`--reuse` 参数）；否则该格重训并在
`runs.json` 中记录，**不混用不同来源的权重**。

注意：历史 run 是用同一份 4K 配置、同一 seed 覆盖方式训出来的，
所以复用不引入训练差异；但复用**必须**用 `last.pt`，不能用当年报告的 `best.pt`，
否则混杂 1 会重新进来。

## 4. 判定规则（写死在代码里）

对每一对架构，按 seed 配对（同一 seed 下 A − B），得到 6 个差值：

- 报 `mean_delta`、`sd_delta`、`wins_left`（差值为负的 seed 数）；
- `|mean_delta| < sd_delta` → **`inconclusive`**，不排序、不写「更优」；
- 否则按符号给出方向。

配对的意义：同一 seed 的两个架构共享训练流与评估计划，差值里不含 seed 方差，
比「两组均值 ± 各自组内 SD」有力得多。

**不做显著性检验**：仓库环境无 scipy；且 n=6 时 SD 本身只有 6 个观测，
算出的 p 值会夸大证据强度。规则只有上面这一条。

## 6. 不可声称

- **6 seed 不足以保证检出**：按历史 SD 粗估，检出 sum vs attn_pair 需要十几个 seed。
  6 seed 的价值在**配对设计 + 换指标**，不在数量。若判定 `inconclusive`，
  只能写「结构差异未检出」，**不能写「四种结构等价」**。
- **容量未匹配**：若 attn_pair 更好，不能归因于「结构」，它大 1.5 倍。
- **只有三个源验证库**，且 `chembl` 是我们输 PRICE 最惨的库，不能代表 26 库整体。
- **不读目标库**，本实验不得用于改写目标库主结论。
- 源验证库已被多轮开发使用，**不是新的独立盲测**。
