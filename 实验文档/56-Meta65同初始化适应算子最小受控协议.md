## 问题与可识别范围

先问“未适应时误差是否已存在”，再问“同一初始化下，head/3 或 last/3 是否稳定加剧特定联合桶误差”。同一 checkpoint 的算子对照固定 support/query，可归因于这次适应操作的条件性差异；跨 checkpoint 是元初始化区组差异，不归因于算子或参数容量。checkpoint × 算子交互只描述这三个既有末态，不能分解元训练 scope、步数、优化轨迹等来源。

## 有限矩阵与实现合同

**3 checkpoint × 3 算子 × 3 库 × 5 run × 1 K = 135 cells**，是本声明三初始化/三库范围内的最小完整交叉矩阵，不是单checkpoint/telstra问题的绝对最小规模。本轮只设计方案，不执行。K20是旧诊断既定焦点，不根据新结果增减K。

| 算子 | 更新范围 | 步数 | 学习率 | loss |

## 指标、聚合与判据

standard unique-query Q50/Q95，linear percentile 在 Q-error 上；不采用 exp(log分位数)、PRICE shifted、跨 run pooled 或比例均值。每 `(checkpoint,db,run,operator)` 保留全部 query ID/hash、FP64真值、表数、原始 log_pred。联合桶、完整分母、小样本规则沿用 [54号](54-Meta65诊断口径复算协议.md)：n<30 仅标注经验分位数不可作稳定判读，n=0 为 null，不丢空 run 求均值。

主定位终点：每checkpoint分别报告telstra `true<100 × 4+` 的none/head/last五run Q95、均值、适应/none均值比及逐query Δlog-Q。三个对照桶为 `<100 × 1-3`、`>=100 × 4+`、`>=100 × 1-3`；完整30联合桶和all/4+作背景；另报chembl/legalacts，不跨checkpoint平均掩盖符号差异。次定位Q50及高估/低估份额，不用这些量回选模型。

- **适应前误差存在**：直接报告 none 的 Q50/Q95、偏置和四组对照；不使用任意误差阈值将“误差大”认证为表征缺陷。
- **预登记描述性支持“稳定加剧”**：同一 checkpoint/operator 主联合桶全部 5 run n≥30，适应/none 的五 run Q95 均值比 >1.10，至少 4/5 run 的 Q95 差为正，5/5 留一均值差为正，逐 run平均 Δlog-Q 至少4/5为正。10% 是定位阈值，不取代原候选退化门槛，也不作显著性阈值；等号不算通过。
- **联合桶增幅与交互分别判读**：每run令 `r=log10(Q95_operator/Q95_none)`，完整四桶交互 `I=(r低高−r低低)−(r非低高−r非低低)`。四桶五run均n≥30（只是描述性准入，非尾部分位数稳定保证）才判读；否则unknown。主桶增幅大于两个边际桶在≥4/5run成立，只称联合桶增幅更强；还要求I至少4/5run>0且5/5留一I均值>0，才称这套计划下的正交互描述性支持。报告每run I/均值/范围，不称显著或一般化机制。单看主桶更大不证明交互；0或反例记录mixed/unsupported，不能认证无影响。
- **区组判读**：若同一算子在不同 checkpoint 方向不同，记录 initialization×operator interaction；若 none 已显示跨区组差异，记录适应前初始化差异。两者可以共存，禁止二择一归因。未达到定位判据不等于“适应无影响”，可能是小效应/样本不足；结果登记 unsupported/mixed/unknown。
- **工程成功**：135 cells 完整、45 diagonal回归锚通过、全部输入/计划/参数/分母认证、独立 CPU 分位数复算通过。与假说成功分开；不满足则 failed/blocked，不产生候选。

执行前现场检查空闲GPU（memory.used≤100MiB且utilization=0）并绑定CUDA_VISIBLE_DEVICES/UUID；没空闲卡即blocked，不换CPU无限运行、不终止他人进程。输出新独立目录，旧输入/PRICE全只读。

输入/checkpoint/code/config/protocol SHA变化、缓存/ID不一致、重复、非有限值、初始化污染、完整query分母为空、diagonal回归失败、超时/资源超限均立即失败。普通联合桶为空按54号保留null，不删除run、不当工程失败；主定位桶/交互桶样本不足则研究判读unknown。留存部分产物但不按部分矩阵下结论。不自动重跑、不扩K/seed/库/lr/scope/步数/损失，不训练或目标评估，不无条件触发S8。

## 后续边界

本协议能隔离**给定初始化与支持计划下**的适应算子影响，不能直接认证表征不足。若确需表征诊断，另提单checkpoint冻结encoder、固定源库support上对同一表征拟合一个预冻结 ridge线性probe，并比较原 head；训练只能在support、正则由事前固定而非query调参，query计划不变，另定预算/条件数/失败判据。该probe仅测这类读出可恢复性，不证明不存在其他可用信息，也不自动重启 S8；本轮不实现或执行。

下一步建议：先授权**实施与预检**这个有限 runner（无 GPU），形成 launch-binding 后再申请一次性 GPU 执行上述135 cells；不要先增加元训练或搜索超参数。
