## 2. 唯一干预的完整定义

每个ERM episode仍合并原support+query；`N=K+64`，逐项损失为原FP32 `SmoothL1(raw_log_pred, log(max(true,1)), beta=1)`，记为 `l_i`。不改变标签、输出或指标floor。

固定上尾条数 `m=ceil(N/10)`，固定混合系数0.5：

```text
A: L = mean(l_i)
B: L = 0.5 * mean(l_i) + 0.5 * upper_tail_mean(l_i, m)
```

正式K=5/10/20/50/100时，N=69/74/84/114/164，m=7/8/9/12/17。实际上尾比例约10.1%–10.8%，**不是精确10%，不是全数据Q95损失，更不是总体CVaR的无偏估计**；本方案称为有限批次上尾混合风险。不试5%/20%或不同混合系数，不根据验证结果改m。

### 阈值并列、梯度与归一化

为避免按输入顺序任意选择等损失样本，令tau为第m大损失，h为严格大于tau的条数、e为等于tau的条数。定义不参与求导的名义系数：

```text
a_i = 1/m                          if l_i > tau
      (m-h)/(m*e)                 if l_i == tau
      0                           if l_i < tau
upper_tail_mean = sum(a_i * l_i)
c_i = 0.5/N + 0.5*a_i
L_B = sum(c_i * l_i)
```

- 排序、tau、比较及系数计算均基于当前训练前向的detached loss；只让逐项 `l_i` 通过 `c_i` 求导。并列采用均匀分配的对称次梯度，数学损失值与最大m项均值相同。
- 全部损失相等时c_i=1/N，两臂数学相同；N=1也退化为原均值。FP32实现须测试数值容限，不强称浮点逐位相等。
- 每episode系数和为1，外层四episode仍等权平均。不是在四episode合并后选难例，不改变数据库采样概率；梯度方向/范数、裁剪触发及Adam更新可变化，这些是干预结果，不调学习率补偿。
- 难例可能来自任何表数、任何基数、任何正负误差方向；不先筛4+，不加S5复杂权重，不依据数据库ID或目标/验证标签分配系数。
- 使用训练真值计算训练loss是正常监督，不是部署特征；推理没有tail选择或额外参数。不得用验证/目标的逐查询误差回填训练权重，也不按已观测的单库尾部造样本。

### 与Q95的关系和局限

对同一查询，未floor的 `exp(abs(raw_log_pred-label))` 与SmoothL1逐项值随绝对log误差单调一致；大于1的误差下SmoothL1保持线性，不像MSE按误差平方持续放大。但正式Q指标使用 `max(raw_log_pred,0)`，负预测时排序可能不同，因此不宣称训练排序与正式Q排序完全一致。

B关注的是源训练episode的尾部均值，**不是直接优化验证4+表Q95**。新源库中的尾部身份可能不同；极端源样本、批次噪声、梯度集中和开发集过拟合都可能使精度变差。0.5均值项保留全体查询的监督底座，但不保证中位数或跨库迁移不退化。
