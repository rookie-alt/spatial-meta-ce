## 3. 模型

### 3.1 架构：分组集合编码器

```text
连接直方图 [J×40] ─┐
fanout     [F×40] ─┤→ 各组共享 token MLP (40/40/4/43 → 64 → 64)
表特征     [T×4]  ─┤  → masked mean + max 池化
过滤条件   [C×43] ─┘
                        ↓
        四组数量 + PG 对数估计 + 表规模对数和
                        ↓
              回归头 (518 → 128 → 64 → 1)
                        ↓
        输出 = PG 对数估计 + 学习到的残差
```

- **参数量：99,777**，纯 FP32 权重 **399,108 字节 ≈ 0.39 MB**
- 无 Dropout / BatchNorm（保证内外循环与评估确定性）
- 最后一层零初始化：未训练模型等价于直接使用 PG
- 按组动态 padding + 独立 mask，**不使用 `-1000` 作为有效输入**

### 3.2 设计取舍

集合池化（mean/max）**不显式编码 join graph 的配对关系**。这是与 PRICE 论文两阶段 self-attention 的主要结构差异，也是尾部精度差距的候选原因（见 §6）。

## 4. 方法：监督式 FOMAML

### 4.1 训练流程

每个 meta-step：

1. 从 23 个训练库随机取 1 个库（`meta_batch=4`，一次 4 个任务）
2. 从该库切分 support（K 从 `[5,10,20,50,100]` 随机）与 query（64 条），二者不重复
3. **内循环**：用 support 计算 SmoothL1 损失，做 5 步梯度更新得到 `fast_params`
4. **外循环**：用 `fast_params` 预测 query，据其损失更新**公共初始化**

关键实现细节：

- `torch.func.functional_call`，`autograd.grad(create_graph=False)`
- 只截断二阶依赖，保留 `fast_param = param - lr*grad` 的初始化通路
- 禁止 `.data` 改写公共参数；每个任务从同一初始化重新开始
- 非有限损失/梯度直接报错，不静默跳过任务
- 外层梯度裁剪 `max_norm=1.0`

**梯度正确性已验证**：标量测试 `w=2, lr=0.1` → fast `w=1.8`，外层梯度 ≈ 1.6，原 `w` 保持 2。

### 4.2 训练配置

| 参数 | 值 |
|---|---|
| method | fomaml |
| outer_lr | 3e-4 (Adam) |
| inner_lr | 1e-3 |
| inner_steps | 5 |
| loss | SmoothL1（在 log-cardinality 上） |
| meta_batch | 4 |
| steps | 2000 |
| validate_every | 100 |
| validation_runs | 5 |
| patience / min_delta | 15 / 1e-3 |
| model selection | 源验证库适应后 **macro mean log-Q95** |

### 4.3 ERM 对照（关键对照）

**同结构、同数据划分、同 seed**，唯一区别是不做内循环适应，直接监督预测。这是判断"收益是否来自元学习"的必要对照。

## 8. 已确认的原代码问题

服务器 `/gly/weilin/PRICE-master` 的旧元学习实现存在以下问题（均已用 CPU 诊断复现）：

| 问题 | 后果 |
|---|---|

| 对已取 log 的表规模再次 log1p | 与历史权重输入语义不符 |

**处理**：原项目保持不动；新项目独立实现，关键问题均写成回归测试。

## 9. 结论与下一步

### 9.1 已证实的优势

1. **模型体积小 107 倍**：实测 0.40 MB / 99,777 参数 vs PRICE 42.84 MB / 10,709,330 参数
2. **Genome 中位数优于 PRICE**：1.218 vs 1.654（唯一胜出的零样本指标）
3. **相对 PG 改善显著**：genome q95 从 383 → 105（3.6 倍）
4. **零样本优于普通训练**：genome 上 FOMAML 比 ERM 好 39%，两 seed 方向一致
5. **训练资源低一个量级**：1×3090 / 约 40 分钟，vs 8×A100 / 5 小时
6. **适应超参更宽容**：PRICE 用 `inner_lr=1e-3` 全参数适应即完全发散，本项目同超参稳定
7. **覆盖 PRICE 未报告的少样本区间**：K = 5~100（价格侧待 LR 调整后对照）
8. **评估协议更严格**：多 seed、支持集重复抽样、unique-query 主指标、逐查询配对、泄漏检查

### 9.2 仍存在的差距

1. **尾部 Q95 落后 1.6~6.7 倍**：stats 66 vs 35.55，genome 115 vs 15.67，ergastf1 24 vs 14.58
2. **零样本 6 项指标中输 5 项**：不能主张精度胜过 PRICE
3. **STATS 出现负迁移**：K=5~100 全部劣于零样本与 PG，约 70% 查询恶化
4. **仅 2 个 seed**：小差距不足以宣称显著
5. **PRICE 少样本对照缺失**：因其适应发散，尚未有可比数字

### 9.3 下一步

| 优先级 | 任务 | 状态 |

| P0 | PRICE 适应 LR 在源验证库搜索（1e-6/1e-5/1e-4） | **待做**——PRICE 用当前超参完全发散，少样本对照无法进行 |

### 9.4 可用于论文的主张

> 在参数量和模型体积小两个数量级（107×）、训练资源低一个量级的前提下，达到与 PRICE 同量级的典型查询精度，并覆盖 PRICE 未评估的少样本适应区间（K≤100）；同时发现 PRICE 对适应步长高度敏感，而轻量模型在同等超参下稳定。

**不可主张**：精度优于 PRICE、整体优于 PRICE——零样本 6 项指标中当前输 5 项。

**主张边界**：中位数精度同量级（差 1~8%）、尾部仍落后 1.6~6.7×，须如实报告。
