## 1. 推荐设计与要回答的有限问题

推荐一次 **seed42、四个线性探针臂的 2×2 screen**：在隔离数据库和查询身份后，重新训练一个共享源模型 F0，固定其权重；比较两个既有表示层级，且在每一层级内用固定步数 Adam 与确定性最小二乘解拟合同一个读出问题。

两个因子：

1. 表示层级：原模型进入 `head` 前的 pooled 向量 `x`，或最后线性输出层之前的 64 维激活 `h`。
2. 求解路径：固定 1000 更新的全批次 Adam，或 FP64 数值最小二乘解 LS。

目的不是再次寻找“最好 loss”，而是得到两个可区分证据：

- **读出优化可达性**：相同表示、目标和样本下，有限步 Adam 距该线性类的数值最优解是否仍有实质拟合差距？
- **表示层级可利用性**：排除线性读出欠求解后，哪个既有层级保留了更可迁移的线性可利用信号？

这是对 S7 unknown 的**窄化机制检验**，不是对整个神经网络的全局优化或原始输入信息上限认证。若主代理要求直接证明“原特征不足”或“整个网络优化失败”，本设计不够，必须重新立项，不能扩大本文结论。

选择逻辑：完整网络换优化器同时牵涉非凸收敛、步长、裁剪与多次 closure，有限预算下很难分离“优化不可达”与“另一个求解器也失败”。线性读出至少提供可独立核验的数值参考。`x/h` 已存在于当前网络，避免新增 SQL 信息、重建缓存、重复映射消融或开启网络容量/loss 常数网格。代价是结论只适用于冻结表示与线性探针。

## 6. 两个表示、同一个探针目标、四个预定臂

### 6.1 表示提取与桥接

对固定 F0，`eval/inference_mode`，无梯度修改 encoder/head：

```text
x = concat(四组 token 编码的 mean/max/sum,
           log1p(四组 counts), pg_log, log_cartesian)
h = F0.head[0:4](x)    # Linear→ReLU→Linear→ReLU，末层 Linear 之前
F0 的 raw_log_pred = pg_log + F0.head[4](h)
```

依据当前 [SetEstimator.forward](../spatial_meta_ce/model.py)，x 为 `4×3×64+6=774` 维、h 为 64 维。这是读取基准的结构推导，不是新特征/新 SQL 信息。提取 API 尚不存在独立正式入口，需最小实现并验证张量恰与原 forward 中间量一致，不复制一个行为漂移的 forward。

x/h 用 F0 原 FP32 前向取得，再转 FP64 做探针矩阵运算。原 FP32 `pg_log` 也转 FP64。在 V 每库按 `(SHA256("s8-bridge-v1|db|query_hash"), query_hash)` 升序固定前 256 条作 F0 桥接：重组原末层 raw 输出与原 forward 最大绝对差 <=1e-4；失败停止，不放宽。这 768 条不能替代 V 完整预测，也不读取 H 做开发桥接。

### 6.2 共同监督与预处理

对表示 z（x 或 h），只从 P 拟合每维 FP64 mean/std；std=0 置 1，否则分母取 `max(std,1e-12)`；不删除零方差维度。V/Q/H 使用 P 的同一变换，不拟合按库归一化或加数据库 ID。

令 `r_i = FP64(F0训练输入的FP32 label_i) - FP64(pg_log_i)`；label 仍是 `log(max(true,1))` 的原训练 dtype，不换 floor。FP64 真值用于正式指标，另报告 FP32 标签误差，不把 probe 数值精度当新增输入信息。

```text
Z_i = [标准化(z_i), 1]
probe raw_log_pred_i = FP64(pg_log_i) + Z_i @ theta
J_z(theta) = (1/19) Σ_db (1/1024) Σ_i∈P_db (Z_i @ theta - r_i)^2
```

因每库 1024 条，J 等于 P 全面板均值 MSE；无正则、无训练尾重权、无 loss 常数搜索。**探针使用 MSE 是为了同问题的确定性最小二乘参照，F0 仍用 SmoothL1。** 不能把读出 MSE 的发现直接归因为 S6 的 SmoothL1 或上尾目标失效，也不能把它包装成重跑 S1 全网络 MSE 臂。

### 6.3 四臂及有效对比

| 臂 | 表示/参数数 | 求解 | 对照职责 |
|---|---|---|---|
| A_h_adam（固定 screen 对照） | h64 / 65 | 全批次 Adam，1000 更新 | 当前末层前表示的有限步读出 |
| B_h_ls | h64 / 65 | 同目标 FP64 LS | B vs A：同表示读出的可达优化差距 |
| C_x_adam | x774 / 775 | 全批次 Adam，1000 更新 | 较早 pooled 表示的有限步读出 |
| D_x_ls | x774 / 775 | 同目标 FP64 LS | D vs C：同表示优化差距；D vs B：数值求解后的层级差异 |

Adam 两臂 theta 全零，初始输出均为 PG；seed42，FP64、lr=3e-4、betas=(0.9,0.999)、eps=1e-8、weight_decay=0，constant LR、无裁剪、无早停，取第1000更新端点。LS 不依赖初始值，但仍保存零初始化定义。两表示不能要求参数初始字节 hash 相同；各 Adam/LS 配对的 Z/r/归一化与零参数 hash 必须相同。

LS 用事前固定 rcond=1e-12 的 SVD 数值最小二乘、最小范数解，返回 rank/奇异值/截断数量/条件摘要，不用正规方程显式求逆。数值 rank 规则不得按验证误差调整，也不加 ridge、改 cutoff 或选择 solver。保存完整 P 残差、J 与归一化正规方程残差；独立核验要求同表示 `J_LS <= J_Adam + 1e-8*max(1,J_Adam)`，以及 `||Zᵀ(Zθ−r)||∞ / max(1,||Z||F ||r||2) <= 1e-8`。不满足即该求解对照未认证，不能宣称达到线性最优。数值截断若实质影响拟合，应标为 `numerical_rank_limited/unknown`，不偷换成表示缺信息。

全部预测同时保留原 F0、原 FP64 PG 参考（二者不列为可调臂）。不做第5个探针、不追加 head 宽度、不试归一化/学习率/loss 网格。

### 6.4 公平性与必须披露的混杂

- **样本公平**：四臂用同一完整 P 与同一标签/目标；求解器对比只在同表示内。Q/H/V 全部使用配对身份。
- **初始化公平**：Adam 同零起点；四臂依赖同一 F0、same seed42；禁止从另一臂的系数继续训练。
- **计算不等价**：1000 次 full-batch Adam 与两次 SVD 不等成本。记录各臂矩阵前向/梯度次数、样本曝光、SVD FLOP 未实测则不报、墙钟、峰值内存及表示提取成本；不写“等步数/等算力公平”。
- **层级不是纯信息因果**：h 是 x 的学习变换，但 linear(h) 与 linear(x) 不是嵌套函数类；65/775 参数、rank/条件数、训练的非线性变换都可能解释 D/B 差异。D 更好仅说明 x 中有本设置下更可利用的信号，不能单独证明 h 丢失了不可恢复信息。
- **隐式偏好**：LS 最小范数与有限步 Adam 的系数范数可能不同；同表示训练 J 差距可量化求解不足，但跨库差距可能含隐式正则/外推效应，不能全归因“优化更好”。
- F0 在 P 上学习表示，probe 也拟合 P，这是训练内机制检验；Q 是事前隔离查询，H 是本轮隔离库，V 是反复使用的开发库，三者不可混称独立盲测。

## 7. 假设、正负结果模式与仍可能 unknown 的分支

定义同表示优化差距 `G_z=(J_Adam−J_LS)/max(J_Adam,1e-12)`；若 J_Adam<=1e-12，仅报告绝对差与“近数值零”，不使用比值。**G>=10%** 是预设实质拟合差距阈值，不是显著性或预期收益。

| 假设/观察模式 | 可区分的结论 | 不允许推出 |
|---|---|---|
| B/A 或 D/C 在 P 上 G>=10%，LS 已数值认证 | 相同固定表示/线性目标存在有限步 Adam 未达到的可达拟合改进 | 全网络 Adam 不可达；S6 上尾 loss 已定位失败原因 |
| 上述拟合差距同时在 Q 与固定 H 上保持 Q95 改善、且保护通过 | 有较强的“固定读出可达性具有迁移意义”线索，值得另冻后续验证 | 已解决空间漂移、适应收益、元学习收益 |
| G>=10% 但 Q/H 不改善或恶化 | 训练可达性不是当前可迁移误差的充分解释；存在拟合/外推取舍 | 单凭更低训练 MSE 宣称瓶颈已解决 |
| B 与 D 均认证；D 比 B 在 Q/H 改善，V 不恶化 | pooled 层在此线性 probe 中更可利用；优先研究 head 变换/读出类别 | 原输入语义充分、末层压缩是唯一因果、需扩宽网络 |
| B 比 D 更好 | 原 head 非线性变换可产生更可利用的信号，简单跳过 head 无支持 | 压缩在所有库无损、所有额外特征都无效 |
| 四臂训练 J 都低但 H Q95 高 | 局部拟合不是充分解释；跨库外推/条件差异仍需研究 | 把粗桶同组当条件已对齐，或用 H 选按库模型 |
| 四臂训练/留出都差；数值认证通过 | 当前冻结表示+线性目标/有限面板未给出有效解释 | 表征信息一定缺失；非线性解码器也必失败 |
| solver/桥接/身份/完整分母失败 | blocked/failed，机制不可判定 | 把工程失败算 no_candidate，或丢失败行后继续 |

本轮不加近邻残差解释、条件重分桶或“误差贡献百分比”。精确表示冲突/语义缺失的专门认证也不附加到首轮，以免变成第三类大审计；**因此没有直接信息不足的证明分支**。这项限制是选择轻量、可核验设计的必要代价。

## 8. 主终点、开发 gate 与留出报告顺序

### 8.1 唯一主终点及预定对比

主终点为每臂在 H 四库 **完整 all-unique 标准 Q95 的等权算术 macro**：

```text
M_H(arm) = [Q95_accidents + Q95_grants + Q95_employee + Q95_hockey] / 4
```

理由：H 完全由身份确定，accidents 无 4+；全 unique 可以保留全部固定库，避免事后换库或把空桶补成好结果。这是 S8 的事前口径，**不是回改 S6 的 4+ 主终点**，不可与旧 44.1443 直接求收益。

事前对比固定为 B/A、D/C（求解路径），D/B（层级）；各比值为相同分母端点的 `M_H(test)/M_H(control)`。不按最有利库、4+ 或训练 MSE 改主终点，不作多比较显著性声明。先逐库计算 Q95，再等权平均；不 pooled、不 macro log-Q95、不平均逐查询 Q-ratio。Q 标准沿用原 `max(pred,1)` 与 `max(true,1)`；raw log 输出不裁剪，非有限/指数溢出停止。

辅助终点：P 的 J/raw MAE；Q 的各库 all/4+ Q50/Q95；H/V 的完整 all/4+ Q50/Q90/Q95，raw MAE/MSE/signed error、预测相对 PG 的改善/恶化数量；H 4+ macro 分母固定三库。true/表数细桶 n<200 只记数量/组成，Q99 仅 n>=1000。不只报告持续旧尾，完整分母是所有主结论的前提。

### 8.2 原 V 开发 gate：先锁提名，再揭示 H 端点

四臂全部预定并完成数值认证后，先在 V 完整预测中处理开发 gate，保存不可回写的 nomination 文件及 SHA，再揭示 H 端点；H 不进入候选排名、阈值选择或 solver 配置。

对 B/C/D，固定 A 与同次 F0 两个参考，成为 `development_promising` 须同时满足：

1. V 三库完整 4+ Q95 等权 macro 同时 <=0.90×A 和 <=0.90×F0；
2. V 每库 all/4+ 的 Q95 与 Q50，均同时 <=1.10×A、<=1.10×F0；
3. 全部四臂身份/来源/端点/LS 数值认证通过，无失败/缺失。

有多个通过者，只按 V 4+ macro 从小到大排序；精确相同按臂名 B→C→D，最多提名一个。无通过者则锁定 `none`，不得到 H 里找“其实不错”的另一臂。gate 参数是草案建议，冻结后不因接近阈值或单库收益放宽。

H 对全部四臂**仍完整一次报告**，避免只留下开发通过臂；这是固定闭环收尾，不启动另一轮训练或重新选型。Q 仅帮助解释，不能推翻 V 提名。

### 8.3 有限 screen 的正负状态及停止

开发提名者在 H 上还须满足 `M_H <=0.90×A` 且 `<=0.90×F0`，每 H 库 all Q50/Q95 及三个非空 4+ 库 Q50/Q95 均 <=1.10×两个参考，才记 `promising_single_seed_probe`。否则为 `no_transfer_candidate`；V 无提名为 `no_development_candidate`。二者都不扩大 seed。

机制标签与候选状态分开：即使 G>=10% 有训练优化差距，未过开发/迁移 gate 也不能追认性能候选；即使过 gate，也不能声称表征因果已证明。数值/来源失败则 `blocked/failed`，不与有效负结果混列。

**未过 gate，本轮停止，不扩 seed、不加第5臂、不延长 Adam、不改 cutoff 或面板。** 通过 gate 也只支持主代理提出独立 seed43/44 确认方案与新预算；不自动执行。种子不能增加独立数据库数量；H 本轮揭示后成为更进一步已见记录，不反复拿它选型。
