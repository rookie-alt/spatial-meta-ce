## 3. 新发现：训练数据量差距约 60 倍

| | PRICE | 本项目（sum, 4000 步预算） |
|---|---|---|
| 训练查询 | 26 库 × 5 万 = 130 万 | 23 库（源训练）× 5 万 |
| 训练遍数 | 150 epoch × batch 512 ≈ **1.95 亿**样本 | ≈ **300 万**（support 225 万 + query 77 万） |
| 模型 | 1070 万参数 | 13 万参数 |

每次训练我们只看到约 1/60 的样本，平均每条训练查询只被看到约 2~3 次。而且 set 在 2000 步前就早停，说明验证指标很早就平了。这可能不是"数据看够了"，而是**小模型 + 元学习目标 + 当前 lr 在少量样本下就停止改善**。

这比 join 结构更可能解释尾部差距：多表查询的真实基数跨度极大，模型需要大量样本才能学好尾部。但它**只是假设**，还没验证。
